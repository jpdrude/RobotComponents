# ![](../../assets/icons/rc/task-list.png){ .rc-icon--title } Task List

<span class="rc-badge">Multi Move tab</span>

In a **Multi Move** cell, each robot runs its own program in its own **task** (`T_ROB1`,
`T_ROB2`, …), and each task needs its own [[RAPID Generator]]. To make the robots wait for
each other or move together, all the programs refer to the same list of tasks: a **Task List**.

[[io:Task List]]

## In RAPID

```
PERS tasks allTasks{2} := [["T_ROB1"], ["T_ROB2"]];
```

The declaration appears under *"Declarations for multi move programming"* in each module that
uses it. Use the **same Task List** (same name, same tasks) in every task's program. ABB's
reference: [RAPID Instructions, Functions and Data types][abb-ifd] ([[abb:tasks]]).

Used by: [[Wait Sync Task]] · [[Sync Move On]].

!!! info "Not checked on a controller"
    The Multi Move code on these pages was generated by Robot Components but not loaded on the
    demo Virtual Controller, which has a single robot and no MultiMove option.
