# ![](../../assets/icons/rc/plane-visualizer.png){ .rc-icon--title } Plane Visualizer

<span class="rc-badge">Utility tab</span>

**Plane Visualizer** draws a plane's axes as arrows: **X red, Y green, Z blue**, the same
colours the target frames use. Use it to check any plane in a definition: is the Z axis
really pointing down, is the work object turned the right way?

[[io:Plane Visualizer]]

Example: the viewport image on [[Work Object]] shows the table plane and the four target
planes drawn with Plane Visualizer.
