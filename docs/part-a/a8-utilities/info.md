# ![](../../assets/icons/rc/info.png){ .rc-icon--title } Info

<span class="rc-badge">Utility tab</span>

**Info** outputs the authors and license information of the installed Robot Components.
Connect a [[gh:Panel]] to read it, e.g. to check which version a definition was made with.
The version number is also shown at the end of every component's tooltip
(e.g. *Robot Components: v1.5.0*) and in the header comment of every generated module.
