# ![](../../assets/icons/rc/multi-relay.png){ .rc-icon--title } Multi Relay

<span class="rc-badge">Utility tab</span>
<span class="rc-badge rc-badge--fork">Fork addition</span>

**Multi Relay** is pure canvas tidying: every input goes straight through to its matching
output, unchanged. Use it to bundle long wires (the robot, the speed, the tool…) that cross
a big definition, so the canvas stays readable, a bit like Grasshopper's Relay but for many
wires at once.

[[io:Multi Relay]]

- Add or remove input/output pairs with the **+ / −** on the component (like Merge) or
  right-click. There is always at least one pair.
- Each pair is named after the type first wired into it (e.g. *Robot*, *Speed Data*), and the
  output mirrors that name. You can rename them by hand; your names are kept.
