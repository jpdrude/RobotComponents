# ![](../../assets/icons/rc/read-rapid-domain.png){ .rc-icon--title } Read Configuration and RAPID Domain

<span class="rc-badge">Controller Utility tab</span>

Two components for advanced use on a connected controller ([[Get Controller]]):

- [[Read Rapid Domain]] reads the value of a RAPID data object (*Task*, *Module*, *Symbol*),
  e.g. the current value of a `PERS num count` your program counts with.
- [[Read Configuration Domain]] reads system parameters from the controller's configuration
  (I/O signals, motion settings, …).
