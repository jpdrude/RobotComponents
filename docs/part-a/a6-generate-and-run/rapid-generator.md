# ![](../../assets/icons/rc/rapid-generator.png){ .rc-icon--title } RAPID Generator

<span class="rc-badge">Code Generation tab</span>
<span class="rc-badge rc-badge--verified">RAPID checked on IRB 1200 · RobotWare 6.10</span>

**RAPID Generator** is where the program comes together: it takes your actions **in order**,
writes the declarations they need (targets, joint positions, your variables), and outputs a
complete RAPID **module** as text. Upload it with [[Upload Program]], or save it from the
right-click menu.

[[io:RAPID Generator]]

## The extra inputs

All on the right-click menu:

| Menu item | What it does |
|---|---|
| Is System Module | Writes a system module (stays loaded on the controller) instead of a program module. |
| Overwrite Module Name / Routine Name | Default `MainModule` / `main`. |
| Set Script Author | Adds an author comment at the top. |
| Specify Routine Scope | `0` GLOBAL, `1` LOCAL, `2` TASK for the main routine. |
| Specify Error Handling | `0` none, `1` pause on error, `2` skip errors. |
| Add Superordinate Main Method | The contents of a superordinate `main`, for when this generator's routine is called from another routine. |
| Add Additional Routines | Your own `PROC`/`FUNC`/`TRAP` from [[Routine]]; see [Part B](../../part-b/index.md). |
| Add Load / Tool / Work Object Data | Writes the `loaddata`, `tooldata`, `wobjdata` declarations into the module. |
| Enforce Axis Limits | On by default: if a target breaks a joint limit, **no code is generated**. Turn it off to get code plus warnings. |
| Output Load / Tool / Work Object Data | Outputs those declarations separately. |
| Save RAPID module to file | Writes the module to a `.mod` file. |

## Reading the output

```
MODULE MainModule
    ! Declarations generated by Robot Components
    VAR robjoint home := [0, 0, 0, 0, 30, 0];
    VAR robtarget target := [[400, 0, 400], [0, 0, 1, 0], [0, 0, 0, 0], [9E9, 9E9, 9E9, 9E9, 9E9, 9E9]];

    PROC main()
        MoveAbsJ [home, [9E9, 9E9, 9E9, 9E9, 9E9, 9E9]], v200, z10, tool0\WObj:=wobj0;
        MoveJ target, v200, fine, tool0\WObj:=wobj0;
    ENDPROC
ENDMODULE
```

Line by line in the [B0 RAPID primer](../../part-b/b0-rapid-primer.md#reading-a-module-line-by-line).
Examples: [Getting started](../../getting-started/index.md), [[Move]].

## Gotchas

!!! warning "Several modules instead of one"
    The generator writes **one module per data-tree branch** of *Actions*. If actions arrive on
    different branches (e.g. points from [[gh:Discontinuity]]), you get several
    `MODULE MainModule` blocks. Right-click *Actions* → **Flatten**. If you use loops or IFs
    ([Part B](../../part-b/index.md)), flatten *their outputs* instead, so the order stays
    right (see the [row tutorial](../../part-b/b8-tutorials/row-loop.md#step-by-step)).

!!! warning "Wire order is program order"
    Actions run in the order the wires were connected to *Actions*. To reorder, disconnect and
    reconnect them, or collect them in a Grasshopper *Merge* component first, whose numbered
    inputs make the order visible.
