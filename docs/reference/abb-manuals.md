# ABB manuals

This wiki **links** to ABB's RAPID documentation but never copies it. Every ABB manual
states: *"This manual and parts thereof must not be reproduced or copied without ABB's
written permission."* So all explanations here are written from scratch, and the
examples are generated by Robot Components itself.

| Manual | Document ID | Use it for |
|---|---|---|
| [Technical reference manual – RAPID Instructions, Functions and Data types][abb-ifd] | 3HAC050917-001 | The full reference for every instruction ([[abb:MoveL]], [[abb:WaitDI]], …), function ([[abb:Offs]], [[abb:CRobT]], …) and data type ([[abb:robtarget]], [[abb:speeddata]], …). |
| [Technical reference manual – RAPID overview][abb-overview] | 3HAC050947-001 | A shorter tour of the language, grouped by topic. |
| [Technical reference manual – RAPID kernel][abb-kernel] | 3HAC050946-001 | The language rules: [[abb-kernel:Data declarations\|declarations]], [[abb-kernel:Expressions\|expressions]], [[abb-kernel:Scope rules for data objects\|scope]], [[abb-kernel:Error recovery\|error handling]]. |

The links open the PDF straight from ABB's library. Links to a specific instruction jump to
its page (`#page=…`); hover over a link to see the manual and page number.

!!! info "Kept up to date automatically"
    The page numbers come from the bookmarks of the current PDFs (revision AC / Y / L) and are
    stored in `docs/data/abb-pages.yml`. **Every publish checks them again**: the Docs workflow
    runs `python tools/docs/abb_pages.py --check` and stops the deployment if a manual can't be
    downloaded or ABB has published a new revision. Then run `python tools/docs/abb_pages.py`,
    review the changes and commit them.

!!! tip "For wiki authors"
    Write `[[abb:MoveL]]` for an instruction, function or data type (instructions manual), and
    `[[abb-kernel:Data declarations]]` or `[[abb-overview:…]]` for a section of the other two.
    Unknown names fail the strict build. For the whole manual, write `[RAPID kernel][abb-kernel]`.
