# ABB manuals

This wiki **links** to ABB's RAPID documentation but never copies it. Every ABB manual
states: *"This manual and parts thereof must not be reproduced or copied without ABB's
written permission."* So all explanations here are written from scratch, and the
examples are generated by Robot Components itself.

| Manual | Document ID | Use it for |
|---|---|---|
| [Technical reference manual – RAPID Instructions, Functions and Data types][abb-ifd] | 3HAC050917-001 | The full reference for every instruction (`MoveL`, `WaitDI`, …), function (`Offs`, `CRobT`, …) and data type (`robtarget`, `speeddata`, …). |
| [Technical reference manual – RAPID overview][abb-overview] | 3HAC050947-001 | A shorter tour of the language, grouped by topic. |
| [Technical reference manual – RAPID kernel][abb-kernel] | 3HAC050946-001 | The language rules: declarations, expressions, scope, error handling. |

The links open a search on [library.abb.com](https://library.abb.com) for that document
ID; pick the revision that matches your RobotWare version.

!!! tip "For wiki authors"
    Write `[MoveL][abb-ifd]` in a page. The link targets are defined once in
    `docs/includes/abb-links.md` and appended to every page automatically, so a changed URL
    is fixed in one place.
